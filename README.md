# Optisend

Nederlandse website om opdrachten te vinden.

## Lokaal starten

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123). De site gebruikt **Inter**, hetzelfde lettertype als MailerLite.

Na inloggen: **Vind opdrachten** (`/klussen`) opent de lijst. Via **Filters** kies je een dienst en vul je postcode en afstand in. **Berichten** (`/berichten`) blijft hetzelfde.
