# Optisend

Nederlandse website om opdrachten en aannemers te vinden.

## Lokaal starten

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123). De site gebruikt **Inter**, hetzelfde lettertype als MailerLite.

Na inloggen: **Vind opdrachten** (`/klussen`) opent de lijst. Wissel van vak via **Diensten**. Schilders hebben filters in de sidebar; andere vakken starten met een lege sidebar. **Vind aannemers** (`/aannemers`) en **Berichten** (`/berichten`) blijven hetzelfde.
