# Optisend

Nederlandse website om opdrachten en aannemers te vinden.

## Lokaal starten

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123). De site gebruikt **Inter**, hetzelfde lettertype als MailerLite.

Na inloggen: **Vind opdrachten** (`/klussen`) opent eerst de vakgebied-keuze. Daarna ga je naar de lijst, bijvoorbeeld `/klussen/vak/schilder` of `/klussen/vak/stukadoor`. Schilders hebben de huidige filters in de sidebar; andere vakken starten met een lege sidebar. **Vind aannemers** (`/aannemers`) en **Berichten** (`/berichten`) blijven hetzelfde.
