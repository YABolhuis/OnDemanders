# Platform

Een website-platform voor pc. Deze eerste versie toont alleen de bovenste menubalk: dezelfde layout als een handelsplatform (logo, navigatie, zoekbalk, account, meldingen, actieknop en een tweede tabrij), zonder tekst.

Inloggen volgt later. Nu is er nog geen authenticatie.

## Lokaal starten

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
